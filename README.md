# SWYNEX-Therapeutic-Area-Brief
HIV-1 Infection and the NNRTI Drug Class :  HIV-1 is managed long-term with combination antiretroviral therapy, INSTI-based at start, while NNRTIs like doravirine suit selected patients. Research gaps: drug resistance, real-world long-term evidence, adherence and access, underrepresented groups, and new combinations or delivery systems.
